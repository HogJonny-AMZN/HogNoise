# The GPU port: implementation plan

**Status:** Accepted 2026-11-14 (merged as [PR #21](https://github.com/HogJonny-AMZN/HogNoise/pull/21)), with its seven decisions; the build is under way on
`feat/gpu-port`. Written from [the spec](../specs/2026-11-14-gpu-port.md),
Accepted 2026-11-14. The build ticks each step as it lands.
**Board:** [`2026-11-01-gpu-fast-track`](../../plan/board/2026-11-01-gpu-fast-track.md)

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to carry this out task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** every HogNoise noise runs on wgpu from one WGSL shader, as an override-only `wgpu` rung, checked against the hog
vectors by a tolerance file written from a committed measurement.

**Architecture:** `hog_noise/gpu.py` holds the device, `GpuSampler` and the rung's registration, importing `wgpu` only
inside its functions; `hog_noise/wgsl/noise.wgsl` is `scalar.py` ported function for function, five compute entry points
over one explicit bind group layout. The harness gains a scaled `within`, a `grid` path and a `Tolerance`;
`tools/measure_gpu.py` measures each adapter and derives the tolerance file's numbers by the spec's rules.

**Tech stack:** Python 3.11 to 3.13, numpy, wgpu-py 0.33 (`wgpu>=0.33,<0.34`), WGSL validated by naga, pytest through the
`pytest` console script (`uv run pytest`, never `python -m pytest`), `uv run python tools/check.py` as the gate.

## Facts this plan rests on

Read from the code at `9049e58` (the merge of the spec), not assumed:

- **wgpu-py 0.33.0** is current. `wgpu.gpu.enumerate_adapters_sync()` lists adapters, each with `adapter.info["device"]`,
  `["backend_type"]` and `["adapter_type"]`; `request_adapter_sync(power_preference="high-performance")` is the default.
  On the owner's machine it lists the RTX 5090 on Vulkan, D3D12 and OpenGL, and **"Microsoft Basic Render Driver"
  (D3D12, `adapter_type` CPU)**, which is WARP: a local run can measure WARP by naming it in `HOG_NOISE_WGPU_ADAPTER`.
- **The ladder** (`backends.py:108-120`) turns a probe that raises into "availability probe raised RuntimeError: <message>",
  and a forced, unavailable rung into `BackendUnavailable` carrying it (`backends.py:169-171`). `make_sampler(params,
  backend=name)` goes through that forced path (`samplers.py:383-399`). Registrations live at `samplers.py:366-380`.
- **`kernel_args()`** (`params.py:430-474`) is 27 scalars whose Python types are, in order,
  `i f i i i f f f f f i i f i i f i i i f i f f i f f f` (`i` an `int`, `f` a `float`). That string is `PARAM_KINDS`.
- **The CPU chain** multiplies the float32 coordinate by the float32 frequency in float32 (`scalar.py:1968-1970`), so the
  GPU's `x * P.frequency` is the same value; everything after is float64 on the CPU and f32 here.
- **The grid**: the CPU's `sample_grid` rounds `(x0 + ix) * sx`, a float64 product, to float32 (`scalar.py:2313-2317`).
- **No recursion is needed**: `_lookup_single2/3` (`scalar.py:904-943`) call the leaf noises directly, never
  `noise_single2/3`, so the call graph has no cycle and WGSL accepts it as written.
- **The tables** are four, concatenated in this order into one 2,048-float buffer: `GRADIENTS_2D` (offset 0),
  `GRADIENTS_3D` (256), `RAND_VECS_2D` (512), `RAND_VECS_3D` (1024) (`tables.py:22, 285, 548, 1067`).
- **The hog set** has 320 cases over 114 features (66 `fnl`, 48 `fns`), every one `points` at `Bound(0)`. Of the 49
  FastNoiseSIMD `scatter_3d` originals without a variant, 3 share their parameters with a FastNoiseLite feature that
  already has a `scatter_2d` case, so the generator's own deduplication yields exactly **46** new 2D cases; with the two
  grids, **48** hog-only cases (the spec's count).
- **The harness** (`conformance.py`): `_points` (441-467) applies `within` as an absolute scale; `_check_case` (411-438)
  never reads a point set's `from`; `CaseResult` (312-327) has no rule field; `Report.table()` (352-373) ends each row with
  the note. No test asserts a hog-set count, so growing the set breaks no assertion.
- **The generator**: `generate_hog` (`gen_noise_vectors.py:398-450`) dedupes on `(params, point_set, output)`;
  `_point_sets` (99-135) and `_point_arrays` (297-310) define the `genasgrid` point sets from `GENASGRID_SCALES`.
  `tests/test_gen_noise_vectors.py` asserts exact hog id lists at 73-93 and case counts at 121, 124, 131 and 178; `test_conformance.py:293` counts the
  white-noise hog cases (2).
- **The boundary test** scans `SRC.glob("*.py")` against one `ALLOWED` set (`test_package_boundary.py:23-60`) and refuses
  `wgpu` in its fresh interpreter (`FORBIDDEN_AT_RUNTIME`, 29-38).
- **The root** `pyproject.toml` has one dependency group, `dev` (`hog-noise[fast,reference,sheets]`, pytest, ruff); CI
  installs the member's extras with pip (`tests.yml:26-31`).

## Decisions made in this plan

The spec leaves these to the plan. Each is reversible, and each is recorded here so the build does not re-decide it:

| Decision | Chosen | Why |
| --- | --- | --- |
| Which features get a *discrete* rule | Those whose name contains `cellvalue`, `noiselookup` or `whitenoise` (`measure_gpu.DISCRETE`); any other feature whose doubled worst passes 1e-2 stops the derivation as a finding | Deterministic, so `test_measure_gpu.py` can re-derive every rule; a jump the list misses cannot pass silently |
| The warp outputs' rule | Continuous, **absolute** (`coordinate_scaled: false`), from the worst absolute difference | The CPU warps raw coordinates in float64 before the frequency multiply (spec, *The warp outputs*); the record shows both numbers |
| The smallest rule number | 1e-7, the smallest candidate step | A doubled worst of 0 (bit-exact on every adapter so far) would make a 0 rule the next adapter fails |
| A discrete rule's range bound | The widest reference range among the feature's cases, rounded up to a 1-2-5 step | The spec's "width of the feature's output range", as a number the record holds |
| `const` tables over the storage buffer | Only if `const` is at least 10% faster, median of five runs, on the owner's GPU | Smaller is noise; the spec keeps storage "unless const is faster" |
| Where each adapter's measurement comes from | The owner's machine for the RTX 5090 and WARP; both CI GPU legs upload theirs (WARP and llvmpipe), each record naming its host | Each measurement needs its adapter; CI's WARP build may differ from the local one, and acceptance 1 runs on CI's |
| The hog-only grid point set | In `POINT_SETS`, written by both writers; `generate_hog` writes its axis files if missing and removes them if it fails | One registry of point sets; a failed run leaves the folder as it was, as the generator promises |

```python
HogNoise: the wgpu rung. Runs where wgpu and an adapter exist; skips with the reason elsewhere, and fails instead of
skipping under HOG_NOISE_REQUIRE_GPU=1 (the software-adapter CI legs), so a leg that loses its adapter cannot go green.
Package: packages/python/hog-noise/tests/test_gpu

import os

import numpy as np
import pytest

from hog_noise import gpu

REQUIRE_GPU = os.environ.get("HOG_NOISE_REQUIRE_GPU") == "1"


@pytest.fixture(scope="module")
def device():
    """The process's device, or a skip (a failure under HOG_NOISE_REQUIRE_GPU=1) naming why there is none."""
    try:
        return gpu.device()
    except RuntimeError as e:
        if REQUIRE_GPU:
            pytest.fail(f"HOG_NOISE_REQUIRE_GPU=1, but {e}")
        pytest.skip(str(e))


PROBE = """
@group(0) @binding(0) var<storage, read_write> OUT : array<f32>;

@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) id : vec3<u32>) {
    if (id.x < arrayLength(&OUT)) {
        OUT[id.x] = f32(id.x) * 0.5;
    }
}
"""


def test_a_device_dispatches_one_pipeline(device):
    """The CI probe: a device exists here and runs a compute pass end to end."""
    import wgpu

    n = 100
    out = device.create_buffer(size=n * 4, usage=wgpu.BufferUsage.STORAGE | wgpu.BufferUsage.COPY_SRC)
    module = device.create_shader_module(code=PROBE)
    pipeline = device.create_compute_pipeline(layout="auto", compute={"module": module, "entry_point": "main"})
    group = device.create_bind_group(
        layout=pipeline.get_bind_group_layout(0),
        entries=[{"binding": 0, "resource": {"buffer": out, "offset": 0, "size": out.size}}],
    )
    encoder = device.create_command_encoder()
    compute = encoder.begin_compute_pass()
    compute.set_pipeline(pipeline)
    compute.set_bind_group(0, group)
    compute.dispatch_workgroups(math.ceil(n / 64))
    compute.end()
    device.queue.submit([encoder.finish()])
    values = np.frombuffer(device.queue.read_buffer(out), dtype=np.float32)
    assert values.tolist() == [i * 0.5 for i in range(n)]
    info = gpu.adapter_info()
    assert info["device"], info
    print(f"adapter: {info}")


def test_without_wgpu_or_an_adapter_the_reason_is_named(monkeypatch):

    monkeypatch.delitem(gpu._STATE, "device", raising=False)  # restored after the test, so the device is kept
```

```python
"""
HogNoise: the wgpu rung, every noise in WGSL on whatever adapter wgpu finds. Override only: never chosen by the ladder.
Package: hog_noise/gpu

`wgpu` is imported inside the functions here and never at the top, so importing `hog_noise`, or using any other rung,
never loads it (Docs/standards/python-project.md, *The package boundary*). One device per process, made on first use
and kept with its pipelines. Spec: Docs/superpowers/specs/2026-11-14-gpu-port.md.
"""

import logging as _logging
import os

_MODULE_NAME = "hog_noise.gpu"
__version__ = "0.1.0"
__updated__ = "2026-11-14"
_LOGGER = _logging.getLogger(_MODULE_NAME)

#: Part of an adapter's name: the first adapter whose name contains it is used instead of wgpu's default.
ADAPTER_ENV = "HOG_NOISE_WGPU_ADAPTER"

#: The process's one device and its adapter's description, made on first use.
_STATE: dict[str, object] = {}


def _wgpu():
    """The wgpu module, or a RuntimeError naming the extra that installs it."""
    try:
        import wgpu
    except ImportError as e:
        raise RuntimeError("wgpu is not installed: install hog-noise[gpu]") from e
    except OSError as e:  # installed, but its native library will not load here
        raise RuntimeError(f"wgpu cannot load its native library: {e}") from e
    return wgpu


def _pick_adapter(wgpu):
    wanted = os.environ.get(ADAPTER_ENV, "").strip()
    if wanted:
        adapters = wgpu.gpu.enumerate_adapters_sync()
        for adapter in adapters:
            if wanted.lower() in str(adapter.info.get("device", "")).lower():
                return adapter
        found = [f"{a.info.get('device')} ({a.info.get('backend_type')})" for a in adapters]
        raise RuntimeError(f"no adapter: none named like {wanted!r} ({ADAPTER_ENV}); found {found}")
    try:
        adapter = wgpu.gpu.request_adapter_sync(power_preference="high-performance")
    except Exception as e:  # wgpu raises its own error types when no adapter exists
        adapter, cause = None, f"{type(e).__name__}: {e}"
    else:
        cause = "wgpu chose none"
    if adapter is None:
        try:
            found = [
                f"{a.info.get('device')} ({a.info.get('backend_type')})" for a in wgpu.gpu.enumerate_adapters_sync()
            ]
        except Exception as e:  # the list is for the message; failing to make it must not hide the cause
            found = [f"cannot list adapters: {e}"]
        raise RuntimeError(f"no adapter: {cause}; found {found}; name one in {ADAPTER_ENV}")
    return adapter


def device():
    """
    The process's one device, made on first use and kept.

    :raises RuntimeError: Naming why there is none: wgpu missing, or no adapter (or none matching `ADAPTER_ENV`).
    """
    if "device" not in _STATE:
        wgpu = _wgpu()
        adapter = _pick_adapter(wgpu)
        try:
            _STATE["device"] = adapter.request_device_sync()
        except Exception as e:  # an adapter that will not give a device is no adapter
            raise RuntimeError(f"no device from {adapter.info.get('device')}: {type(e).__name__}: {e}") from e
        _STATE["info"] = {k: adapter.info.get(k) for k in ("device", "backend_type", "adapter_type", "vendor")}
        info = _STATE["info"]
        _LOGGER.info(f"wgpu adapter: {info['device']} ({info['backend_type']}, {info['adapter_type']})")
    return _STATE["device"]


def adapter_info() -> dict[str, object]:
    """The chosen adapter's name, back end, type and vendor, making the device if it is not made yet."""
    device()
    return dict(_STATE["info"])


def is_available() -> bool:
    """The ladder's probe: makes the device, or raises with the cause so the ladder's message carries it."""
    device()
    return True


if __name__ == "__main__":
    _logging.basicConfig(level=_logging.INFO)
    try:
        print(adapter_info())
    except RuntimeError as e:
        print(f"no GPU here: {e}")
```

```python
def test_a_scaled_within_holds_each_point_to_its_own_allowance(tmp_path):
    """Acceptance 3: a point above its own allowance but below the set's largest fails, so an allowance applied to the
    whole set instead of per point is caught. make_vectors' points have max |axis| 10, 1000, 300 and 2000; at f = 0.01
    a scale of 1e-3 allows 1e-3, 1e-2, 3e-3 and 2e-2."""

    rule = {
        "kind": "points",
        "bound": {"scale": 1.0, "coordinate_scaled": False},
        "within": {"scale": 1e-3, "coordinate_scaled": True, "fraction": 1.0},
    }
    root = make_vectors(tmp_path, [a_case("original/t/f/p3", "o/f.f32", compare=rule)], {"o/f.f32": ref})
    above_its_own = np.array([5e-3, 0.0, 0.0, 0.0], np.float32)
    assert conformance.check(_values(above_its_own), root, reference="original").results[0].status == "fail"
```

```python
#: The tolerance file format this module reads (the GPU port's spec, *The tolerance*).
TOLERANCE_FORMAT = 1
_RULE_KINDS = ("continuous", "discrete")


def _points_rule(rule: Mapping[str, object]) -> dict[str, object]:
    """A tolerance rule as the points rule `_points` judges: continuous is a bound alone; discrete adds within and a
    correlation. ``rule`` records the kind, which `_points` reports."""
    kind = rule.get("kind")
    if kind not in _RULE_KINDS:
        raise ConformanceError(f"kind {kind!r}, not one of {_RULE_KINDS}")
    points: dict[str, object] = {"kind": "points", "bound": rule.get("bound"), "rule": kind}
    extra = sorted({"within", "min_correlation"} & set(rule))
    if kind == "continuous" and extra:
        raise ConformanceError(f"a continuous rule has a bound and nothing else, not {extra}")
    if kind == "discrete":
        missing = sorted({"within", "min_correlation"} - set(rule))
        if missing:
            raise ConformanceError(f"a discrete rule needs {missing}")
        points["within"] = rule["within"]
        points["min_correlation"] = rule["min_correlation"]
    _check_rule(points)
    return points


def _feature(case: Case) -> str:
    """``<library dir>/<feature>``, the middle of a case id."""
    return "/".join(case.id.split("/")[1:3])


@dataclasses.dataclass(frozen=True)
class Tolerance:
    """
    One rendering's bounds against the hog set, from ``vectors/tolerance/<rendering>.json``: one rule per feature and
    output, each continuous or discrete, judged as a points rule.
    """

    rendering: str
    range: Mapping[str, object]
    rules: Mapping[tuple[str, str | None], Mapping[str, object]]  # (feature, output or None) -> points rule

    def rule_for(self, case: Case) -> Mapping[str, object] | None:
        """The rule covering ``case``: its output's own, else its feature's, else None."""
        feature = _feature(case)
        return self.rules.get((feature, case.output)) or self.rules.get((feature, None))

    @classmethod
    def load(cls, path: str | Path, vectors: Vectors) -> "Tolerance":
        """
        Read a tolerance file and check it against ``vectors``' hog features.

        :raises ConformanceError: An unreadable or malformed file, a rule naming no hog feature, two rules covering one
            case, or a malformed rule. Every message names the part that is wrong.
        """
        path = Path(path)
        try:
            data = json.loads(path.read_text(encoding="utf-8"))
        except (OSError, UnicodeDecodeError, json.JSONDecodeError) as e:
            raise ConformanceError(f"{path}: cannot be read as JSON ({e})") from e
        found = data.get("format") if isinstance(data, dict) else None
        if found != TOLERANCE_FORMAT:
            raise ConformanceError(f"{path}: tolerance format {found!r}, this reads {TOLERANCE_FORMAT}")
        if not (
            isinstance(data.get("rendering"), str)
            and isinstance(data.get("range"), dict)
            and isinstance(data.get("rules"), list)
        ):
            raise ConformanceError(f"{path}: needs a 'rendering' string, a 'range' object and a 'rules' list")
        features = {_feature(c) for c in vectors.cases if c.set == "hog"}
        rules: dict[tuple[str, str | None], Mapping[str, object]] = {}
        covered: dict[str, set[str]] = {}
        for i, rule in enumerate(data["rules"]):
            where = f"{path}: rule {i}"
            feature = rule.get("feature") if isinstance(rule, dict) else rule
            if feature not in features:
                raise ConformanceError(f"{where}: feature {feature!r} names no hog feature in {vectors.root}")
            output = rule.get("output")
            if output not in (None, "noise", "warp"):
                raise ConformanceError(f"{where}: output {output!r}, not 'noise' or 'warp'")
            covers = {"noise", "warp"} if output is None else {output}
            clash = covers & covered.get(feature, set())
            if clash:
                raise ConformanceError(f"{where}: {feature} already has a rule covering its {sorted(clash)} cases")
            covered.setdefault(feature, set()).update(covers)
            try:
                rules[(feature, output)] = _points_rule(rule)
            except ConformanceError as e:
                raise ConformanceError(f"{where} ({feature}): {e}") from e
```

```python
def close_to_the_cpu(select: str) -> int:
    """
    Every hog case matching ``select``, on the GPU, finite and within DEV_SCALE per point (coordinate-scaled) at every
    point (99% for a discrete feature); grids through ``sample_grid``. Returns how many cases it checked, so a pattern
    that matches nothing fails.
    """
    vectors = conformance.load(VECTORS, sets="hog")
    sample, warp = conformance.renderings("wgpu")
    grid = conformance.grid_rendering("wgpu")
    tight = Bound(DEV_SCALE, coordinate_scaled=True)
    checked = 0
    for case in vectors.cases:
        if not fnmatch.fnmatchcase(case.id, select):
            continue
        ps = vectors.point_sets[case.point_set]
        if ps.origin is not None and case.output == "noise":
            o = ps.origin
            ours = grid(case.params, tuple(o["start"]), tuple(o["shape"]), tuple(o["scales"])).ravel()
        else:
            fn = warp if case.output == "warp" else sample
            ours = fn(case.params, ps.axes[0], ps.axes[1], ps.axes[2] if ps.dims == 3 else None)
        ours = np.asarray(ours, np.float32)
        assert ours.shape == case.values.shape, case.id
        assert np.isfinite(ours).all(), f"{case.id}: not finite"
        diff = np.abs(ours.astype(np.float64) - case.values.astype(np.float64))
        if diff.ndim == 2:
            diff = diff.max(axis=1)
        within = float(np.mean(diff <= tight.per_point(case.params.frequency, ps.axes)))
        need = 0.99 if any(k in case.id for k in DEV_DISCRETE) else 1.0
        assert within >= need, f"{case.id}: {within:.4f} of points within {DEV_SCALE} scaled; max {diff.max():.3e}"
        checked += 1
    assert checked, f"no hog case matches {select!r}"
    return checked
```

```python
MAX_OCTAVES = 32
WORKGROUP = 64
_MAX_GROUPS = 65535
#: The shader's ``Params`` struct, field for field in `NoiseParams.kernel_args()` order: ``i`` an i32, ``f`` an f32.
PARAM_KINDS = "ifiiifffffiifiifiiififfifff"
ENTRY_POINTS = ("sample_points_3d", "sample_points_2d", "sample_grid", "warp_points_3d", "warp_points_2d")


def pack_params(params: NoiseParams) -> bytes:
    """The ``Params`` uniform: `kernel_args()` with the seed wrapped to i32, little-endian, padded to 16 bytes."""
    args = list(params.kernel_args())
    args[0] = ((int(args[0]) + 0x80000000) & 0xFFFFFFFF) - 0x80000000
    values = [int(a) if kind == "i" else float(a) for kind, a in zip(PARAM_KINDS, args, strict=True)]
    data = struct.pack("<" + PARAM_KINDS, *values)
    return data + bytes(-len(data) % 16)


def pack_grid(start, shape, scales) -> bytes:
    """The ``Grid`` uniform: the start cell, the shape and the per-axis scales, padded to 16 bytes."""
    data = struct.pack("<iiiIIIfff", *(int(v) for v in start), *(int(n) for n in shape), *(float(s) for s in scales))
    return data + bytes(-len(data) % 16)


def _workgroups(n: int) -> tuple[int, int, int]:
    """Workgroups for ``n`` points: along x, wrapping into y past the 65,535 a dimension allows (``point_index``)."""
    groups = math.ceil(n / WORKGROUP)
    if groups <= _MAX_GROUPS:
        return (groups, 1, 1)
    return (_MAX_GROUPS, math.ceil(groups / _MAX_GROUPS), 1)

class _Gpu:
    """The process's one device, the buffers that never change, and one pipeline per entry point."""

    _instance: "_Gpu | None" = None

    @classmethod
    def get(cls) -> "_Gpu":
        if cls._instance is None:
            cls._instance = cls(device())
        return cls._instance

    def __init__(self, dev) -> None:
        wgpu = _wgpu()
        self.wgpu, self.device = wgpu, dev
        source = (importlib.resources.files("hog_noise") / "wgsl" / "noise.wgsl").read_text(encoding="utf-8")
        t0 = time.perf_counter()
        module = dev.create_shader_module(code=source)  # naga validates here
        stage, kind = wgpu.ShaderStage.COMPUTE, wgpu.BufferBindingType
        layout = [kind.uniform, kind.read_only_storage, kind.read_only_storage, kind.read_only_storage,
                  kind.read_only_storage, kind.storage, kind.uniform]  # fmt: skip
        self.layout = dev.create_bind_group_layout(
            entries=[{"binding": i, "visibility": stage, "buffer": {"type": t}} for i, t in enumerate(layout)]
        )
        pipeline_layout = dev.create_pipeline_layout(bind_group_layouts=[self.layout])
        self.pipelines = {
            name: dev.create_compute_pipeline(layout=pipeline_layout, compute={"module": module, "entry_point": name})
            for name in ENTRY_POINTS
        }
        _LOGGER.info(f"noise.wgsl: {len(ENTRY_POINTS)} pipelines built in {1000 * (time.perf_counter() - t0):.0f} ms")
        table = np.concatenate([tables.GRADIENTS_2D, tables.GRADIENTS_3D, tables.RAND_VECS_2D, tables.RAND_VECS_3D])
        self.tables = self.storage(table)
        self.unused = self.storage(np.zeros(1, np.float32))  # bound where an entry point reads nothing
        self.no_grid = self.uniform(bytes(48))

    def storage(self, values: NDArray) -> object:
        data = np.ascontiguousarray(values, dtype=np.float32).tobytes()
        return self.device.create_buffer_with_data(data=data, usage=self.wgpu.BufferUsage.STORAGE)

    def uniform(self, data: bytes) -> object:
        return self.device.create_buffer_with_data(data=data, usage=self.wgpu.BufferUsage.UNIFORM)

    def run(self, entry: str, params_buffer, axes, n: int, width: int, grid=None) -> NDArray[np.float32]:
        """Dispatch ``entry`` over ``n`` points and read back ``n * width`` floats."""
        if n == 0:
            return np.empty(0, np.float32)
        wgpu, dev = self.wgpu, self.device
        coords = [self.storage(a) for a in axes] + [self.unused] * (3 - len(axes))
        out = dev.create_buffer(size=n * width * 4, usage=wgpu.BufferUsage.STORAGE | wgpu.BufferUsage.COPY_SRC)
        buffers = [params_buffer, self.tables, *coords, out, grid if grid is not None else self.no_grid]
        group = dev.create_bind_group(
            layout=self.layout,
            entries=[
                {"binding": i, "resource": {"buffer": b, "offset": 0, "size": b.size}} for i, b in enumerate(buffers)
            ],
        )
        encoder = dev.create_command_encoder()
        compute = encoder.begin_compute_pass()
        compute.set_pipeline(self.pipelines[entry])
        compute.set_bind_group(0, group)
        compute.dispatch_workgroups(*_workgroups(n))
        compute.end()
        dev.queue.submit([encoder.finish()])
        return np.frombuffer(dev.queue.read_buffer(out), dtype=np.float32).copy()


class GpuSampler:
    """The wgpu rung's sampler: the calls every sampler has, run by noise.wgsl on the process's one device."""

    name = "wgpu"

    def __init__(self, params: NoiseParams) -> None:
        for field in ("octaves", "perturb_octaves"):
            value = getattr(params, field)
            if value > MAX_OCTAVES:
                raise NotImplementedError(
                    f"{field}={value} is past the wgpu rung's cap of {MAX_OCTAVES}: a shader loop that long can stall "
                    f"the device"
                )
        _check_ported(params)
        self.params = params
        self._gpu = _Gpu.get()
        self._params = self._gpu.uniform(pack_params(params))

    def sample_points(self, xs, ys, zs, out: NDArray[np.float32]) -> NDArray[np.float32]:
        out[...] = self._gpu.run("sample_points_3d", self._params, (xs, ys, zs), len(xs), 1)
        return out

    def sample_points_2d(self, xs, ys, out: NDArray[np.float32]) -> NDArray[np.float32]:
        out[...] = self._gpu.run("sample_points_2d", self._params, (xs, ys), len(xs), 1)
        return out

    def sample_grid(self, start, shape, scales=(1.0, 1.0, 1.0)) -> NDArray[np.float32]:
        shape = tuple(int(n) for n in shape)
        grid = self._gpu.uniform(pack_grid(start, shape, scales))
        return self._gpu.run("sample_grid", self._params, (), math.prod(shape), 1, grid).reshape(shape)

    def warp_points(self, xs, ys, zs) -> NDArray[np.float32]:
        return self._gpu.run("warp_points_3d", self._params, (xs, ys, zs), len(xs), 3).reshape(len(xs), 3)

    def warp_points_2d(self, xs, ys) -> NDArray[np.float32]:
        return self._gpu.run("warp_points_2d", self._params, (xs, ys), len(xs), 2).reshape(len(xs), 2)

    def sample(self, x: float, y: float, z: float = 0.0) -> float:
        """`sample_points` on one point: correct, and slow on purpose (a dispatch per value)."""
        one = np.empty(1, np.float32)
        return float(
            self.sample_points(np.array([x], np.float32), np.array([y], np.float32), np.array([z], np.float32), one)[0]
        )


register(
    Backend(CAPABILITY, "wgpu", PRIORITY, is_available, GpuSampler, note="noise.wgsl on wgpu, float32; override only")
)
```

  **The conventions**, one place, used by every shader task:
  - A CPU integer is `i32`, a CPU float `f32`. `_wrap32(a * b)` is `a * b`; `_wrap32(h << 19)` is `h << 19u`; `h >> 15`
    is `h >> 15u` (arithmetic on i32). Every hash constant fits in i32 and is written as an i32 literal.
  - `int(f)` is `i32(f)` (truncation toward zero, as Python's); `np.floor(f)` is `floor(f)`; `np.sqrt` is `sqrt`; `abs`
    is `abs`; an integer times a float is `f32(h) * k`.
  - A table read `GRADIENTS_2D[i]` is `gradients_2d(i)`, and likewise for the other three.
  - A function returning a tuple returns `vec2<f32>` or `vec3<f32>`; a tuple of mixed kinds returns a small `struct`
    named after the function (`struct Cellular2Scan { ... }`).
  - `if h & 1:` is `if ((h & 1) != 0)`; Python's chained `a if c else b` is `select(b, a, c)` only when both sides are
    cheap and side-effect free, else an `if`.
  - A CPU float64 literal keeps every digit the CPU writes; WGSL rounds it to f32 once.
  - The function keeps the CPU's name and parameter order. If naga rejects a name as reserved, add a trailing `_` and
    say so in its comment.
  - **A constant expression must not overflow.** WGSL evaluates `PRIME_Y << 1` on two `const`s at shader creation, and
    an overflowing signed shift is an error there. `scalar.py` writes `_wrap32(PRIME_X << 1)` and its Y and Z twins
    (lines 306, 390, 652, 707, 726, 727, 746, 764): declare them wrapped, `const PRIME_X2 : i32 = 1002250642;`,
    `const PRIME_Y2 : i32 = -2021106534;`, `const PRIME_Z2 : i32 = -854139810;`, and use those.
  - **A parameter is immutable.** Where the CPU reassigns a parameter (`_ping_pong`'s `t -= ...`, the fractals'
    `seed += 1`), name the parameter `<name>_in` and start the body with `var <name> = <name>_in;`.

```python
"""
HogNoise: measure the wgpu rung against the hog set on this machine's adapter, and derive the tolerance file from every
adapter's measurement (the GPU port's spec, *How a number is fixed*).
Package: tools/measure_gpu

    uv run --group gpu python tools/measure_gpu.py run                  # this adapter -> vectors/reports/gpu/<commit>/
    uv run python tools/measure_gpu.py derive vectors/reports/gpu/<commit>   # every adapter -> the rules and the tables

`run` writes one JSON file per adapter, so the owner's GPU, WARP and CI's llvmpipe each add their own. `derive` reads them
all and writes `vectors/tolerance/wgpu.json`, `vectors/portability-gpu.md` and the folder's `record.md`. The rules follow
from the record alone, so tests/test_measure_gpu.py can recompute every committed number.
"""

import argparse
import collections
import json
import logging as _logging
import math
import os
import re
import subprocess
import sys
from pathlib import Path

import numpy as np

from hog_noise import compare, conformance
from hog_noise.conformance import Bound

_MODULE_NAME = "measure_gpu"
_LOGGER = _logging.getLogger(_MODULE_NAME)

ROOT = Path(__file__).resolve().parents[1]
VECTORS = ROOT / "vectors"
#: Every 1, 2 or 5 step from 1e-7 to 1e-2: the tight bounds a discrete rule may take.
CANDIDATES = [float(f"{m}e{e}") for e in range(-7, -2) for m in (1, 2, 5)] + [1e-2]
CANDIDATE_KEYS = [f"{c:.0e}" for c in CANDIDATES]
#: Features whose output jumps where float32 flips a choice (this plan's decision): judged by a discrete rule.
DISCRETE = ("cellvalue", "noiselookup", "whitenoise")
#: Past this, a doubled worst is no longer drift: the derivation stops and the owner decides.
LARGEST = 1e-2


class Finding(Exception):
    """A measurement the rules cannot turn into a number: the owner's decision, in the pull request."""


def step_up(x: float) -> float:
    """The smallest 1, 2 or 5 step at or above ``x``, and never below the smallest candidate (2.03e-6 -> 5e-6)."""
    if not x > CANDIDATES[0]:
        return CANDIDATES[0]
    exponent = math.floor(math.log10(x))
    for e in (exponent, exponent + 1):
        for m in (1, 2, 5):
            step = float(f"{m}e{e}")
            if step >= x * (1.0 - 1e-9):
                return step
    raise AssertionError(x)  # unreachable: 1e(exponent + 1) is always at or above x


def floor3(x: float) -> float:
    """``x`` rounded down to three decimal places, without float noise turning 0.999 into 0.998."""
    return math.floor(x * 1000.0 + 1e-9) / 1000.0


def feature_of(case_id: str) -> str:
    return "/".join(case_id.split("/")[1:3])


def measure(vectors, sample, warp, grid) -> dict[str, dict]:
    """Per hog case, the numbers the rules are derived from."""
    unit = Bound(1.0, coordinate_scaled=True)
    cases: dict[str, dict] = {}
    for case in vectors.cases:
        if case.set != "hog":
            continue
        ps = vectors.point_sets[case.point_set]
        if ps.origin is not None and case.output == "noise":
            o = ps.origin
            ours = grid(case.params, tuple(o["start"]), tuple(o["shape"]), tuple(o["scales"])).ravel()
        else:
            fn = warp if case.output == "warp" else sample
            ours = fn(case.params, ps.axes[0], ps.axes[1], ps.axes[2] if ps.dims == 3 else None)
        ours = np.asarray(ours, np.float32)
        bad = int(np.count_nonzero(~np.isfinite(ours)))
        if bad:  # NaN would make every statistic NaN, and step_up(NaN) the tightest rule there is
            raise Finding(f"{case.id}: the GPU wrote {bad} values that are not finite")
        diff = np.abs(ours.astype(np.float64) - case.values.astype(np.float64))
        if diff.ndim == 2:
            diff = diff.max(axis=1)
        normalised = diff / unit.per_point(case.params.frequency, ps.axes)
        cases[case.id] = {
            "feature": feature_of(case.id),
            "output": case.output,
            "max_abs": float(diff.max()),
            "max_normalised": float(normalised.max()),
            "p99_normalised": float(np.quantile(normalised, 0.99)),
            "correlation": float(compare.compare_values(ours.ravel(), case.values.ravel()).correlation),
            "outside": {key: float(np.mean(normalised > c)) for key, c in zip(CANDIDATE_KEYS, CANDIDATES, strict=True)},
            "ref_range": float(case.values.max() - case.values.min()),
        }
    return cases


def derive(records: list[dict]) -> list[dict]:
    """
    The rules, from every adapter's record, by the spec's rules and this plan's decisions.

    :raises Finding: A continuous feature past `LARGEST`, or a discrete one flipping more than 1% of points.
    """
    groups: dict[tuple[str, str], list[dict]] = collections.defaultdict(list)
    outputs: dict[str, set[str]] = collections.defaultdict(set)
    for rec in records:
        for s in rec["cases"].values():
            groups[(s["feature"], s["output"])].append(s)
            outputs[s["feature"]].add(s["output"])
    rules = []
    for (feature, output), stats in sorted(groups.items()):
        for s in stats:  # a record written by hand or by an older tool is held to the same standard as `measure`'s
            numbers = [s[k] for k in ("max_abs", "max_normalised", "p99_normalised", "correlation", "ref_range")]
            if not all(math.isfinite(v) for v in [*numbers, *s["outside"].values()]):
                raise Finding(f"{feature} {output}: a measurement that is not finite")
        rule: dict[str, object] = {"feature": feature}
        if len(outputs[feature]) > 1:
            rule["output"] = output
        if output == "warp":
            scale = step_up(2.0 * max(s["max_abs"] for s in stats))
            if scale > LARGEST:
                raise Finding(f"{feature} warp: absolute {scale} past {LARGEST}")
            rule.update(kind="continuous", bound={"scale": scale, "coordinate_scaled": False})
        elif any(k in feature for k in DISCRETE):
            within = step_up(2.0 * max(s["p99_normalised"] for s in stats))
            if within > LARGEST:
                raise Finding(f"{feature}: its 99th percentile is itself a flip, more than 1% of points")
            key = f"{within:.0e}"
            outside = max(s["outside"][key] for s in stats)
            if outside > 0.01:
                raise Finding(f"{feature}: {outside:.4f} of points outside {within}, more than 1%")
            rule.update(
                kind="discrete",
                bound={"scale": step_up(max(s["ref_range"] for s in stats)), "coordinate_scaled": False},
                within={"scale": within, "coordinate_scaled": True, "fraction": floor3(1.0 - 2.0 * outside)},
                min_correlation=floor3(min(s["correlation"] for s in stats)),
            )
        else:
            scale = step_up(2.0 * max(s["max_normalised"] for s in stats))
            if scale > LARGEST:
                raise Finding(f"{feature}: {scale} past {LARGEST}; a jump the DISCRETE list does not name")
            rule.update(kind="continuous", bound={"scale": scale, "coordinate_scaled": True})
        rules.append(rule)
    return rules


def read_records(folder: Path) -> list[dict]:
    """Every adapter's record in ``folder``, by file name."""
    return [json.loads(p.read_text(encoding="utf-8")) for p in sorted(folder.glob("*.json"))]


def measured_range(vectors) -> dict[str, object]:
    """The frequencies and the largest noise-space coordinate of the hog set: what the rules hold over."""
    hog = [c for c in vectors.cases if c.set == "hog"]
    reach = max(
        float(np.max(np.abs(np.stack(vectors.point_sets[c.point_set].axes)))) * abs(c.params.frequency) for c in hog
    )
    return {
        "frequency": sorted({c.params.frequency for c in hog}),
        "noise_coordinate_max": math.ceil(reach * 100) / 100,
    }


#: Set on CI to the pull request's head, since a pull_request run checks out a merge commit nobody else can measure at.
COMMIT_ENV = "HOG_NOISE_MEASURED_COMMIT"
#: Where a measurement was taken (CI sets "ci-windows" or "ci-ubuntu"); two runs of one adapter are kept apart by it.
HOST_ENV = "HOG_NOISE_MEASURE_HOST"


def _commit() -> str:
    pinned = os.environ.get(COMMIT_ENV, "").strip()
    if pinned:
        return pinned[:7]
    return subprocess.run(
        ["git", "rev-parse", "--short", "HEAD"], capture_output=True, text=True, check=True
    ).stdout.strip()


def label(record: dict) -> str:
    """An adapter's record, named: device, back end and where it ran."""
    return f"{record['adapter']['device']} ({record['adapter']['backend_type']}) on {record['host']}"


def _slug(text: str) -> str:
    return re.sub(r"[^a-z0-9]+", "-", text.lower()).strip("-")


def run(out: Path) -> Path:
    from hog_noise import gpu

    vectors = conformance.load(VECTORS)
    sample, warp = conformance.renderings("wgpu")
    info = gpu.adapter_info()
    data = {
        "adapter": info,
        "host": os.environ.get(HOST_ENV, "").strip() or "local",
        "commit": _commit(),
        "cases": measure(vectors, sample, warp, conformance.grid_rendering("wgpu")),
    }
    out.mkdir(parents=True, exist_ok=True)
    path = out / f"{_slug(label(data))}.json"
    path.write_text(json.dumps(data, indent=1, sort_keys=True) + "\n", encoding="utf-8", newline="\n")
    _LOGGER.info(f"measured {len(data['cases'])} hog cases on {info['device']} ({info['backend_type']}) -> {path}")
    return path


def _tables(records: list[dict], rules: list[dict]) -> tuple[str, str]:
    """``record.md`` (per case and adapter) and ``portability-gpu.md`` (per feature and adapter)."""
    adapters = [label(r) for r in records]
    tight = {r["feature"]: f"{r['within']['scale']:.0e}" for r in rules if r["kind"] == "discrete"}
    lines = ["# The wgpu rung against the hog set, per feature", "", "Written by `tools/measure_gpu.py derive`.", "",
             "| Feature | " + " | ".join(adapters) + " |", "| --- |" + " --- |" * len(adapters)]  # fmt: skip
    per_case = ["# The measurement, per case", "", "| Case | Adapter | Max abs | Max / unit | p99 / unit | Corr |",
                "| --- | --- | --- | --- | --- | --- |"]  # fmt: skip
    features = sorted({s["feature"] for r in records for s in r["cases"].values()})
    for feature in features:
        cells = []
        for r in records:
            stats = [s for s in r["cases"].values() if s["feature"] == feature]
            worst = max(s["max_normalised"] for s in stats)
            cell = f"{worst:.2e}"
            if feature in tight:
                cell += f", {max(s['outside'][tight[feature]] for s in stats):.4f} flipped"
            cells.append(cell)
        lines.append(f"| {feature} | " + " | ".join(cells) + " |")
    for r, name in zip(records, adapters, strict=True):
        for case_id, s in sorted(r["cases"].items()):
            per_case.append(
                f"| {case_id} | {name} | {s['max_abs']:.2e} | {s['max_normalised']:.2e} | {s['p99_normalised']:.2e} "
                f"| {s['correlation']:.6f} |"
            )
    return "\n".join(per_case) + "\n", "\n".join(lines) + "\n"


def derive_files(folder: Path) -> list[Path]:
    records = read_records(folder)
    rules = derive(records)
    vectors = conformance.load(VECTORS)
    tolerance = {
        "format": conformance.TOLERANCE_FORMAT,
        "rendering": "wgpu",
        "range": measured_range(vectors),
        "measured": {
            "record": folder.relative_to(VECTORS).as_posix() + "/",
            "adapters": [label(r) for r in records],
        },
        "rules": rules,
    }
    record_md, portability = _tables(records, rules)
    written = [VECTORS / "tolerance" / "wgpu.json", VECTORS / "portability-gpu.md", folder / "record.md"]
    written[0].parent.mkdir(parents=True, exist_ok=True)
    written[0].write_text(json.dumps(tolerance, indent=2) + "\n", encoding="utf-8", newline="\n")
    written[1].write_text(portability, encoding="utf-8", newline="\n")
    written[2].write_text(record_md, encoding="utf-8", newline="\n")
    _LOGGER.info(f"derived {len(rules)} rules from {len(records)} adapters: {[str(p) for p in written]}")
    return written


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(prog="measure_gpu", description=__doc__.split("\n\n")[0])
    sub = parser.add_subparsers(dest="command", required=True)
    run_p = sub.add_parser("run", help="measure this machine's adapter")
    run_p.add_argument("--out", type=Path, default=None, help="default: vectors/reports/gpu/<commit>/")
    derive_p = sub.add_parser("derive", help="derive the rules and tables from every adapter's record in a folder")
    derive_p.add_argument("folder", type=Path)
    args = parser.parse_args(argv)
    _logging.basicConfig(level=_logging.INFO, format="%(asctime)s %(levelname)s %(name)s %(message)s")
    if args.command == "run":
        try:
            run(args.out or VECTORS / "reports" / "gpu" / _commit())
        except Finding as e:
            _LOGGER.error(f"a finding for the owner, not a number: {e}")
            return 1
        return 0
    try:
        derive_files(args.folder.resolve())
    except Finding as e:
        _LOGGER.error(f"a finding for the owner, not a number: {e}")
        return 1
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
