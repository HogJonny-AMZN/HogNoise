### The harness spec
**By:** @HogJonny-AMZN · **Agent:** Claude Code (claude-opus-5-5)

Written from the code, not the design's assumptions, and four things the design did not know came out of it: the suite's
pointwise limits for the originals are per feature (5e-5 to 1e-3, some with a correlation floor), not the comparison
table's classes; `simplex_billow` is compared twice, by point as classic Simplex and by shape as OpenSimplex2; 32
FastNoiseSIMD files are read by no test and become advisory cases rather than vanish; and `NoiseParams` has no
`to_dict`/`from_dict`, so the spec adds them. A partial port (the GPU rung's first 2D OpenSimplex2) raises
`NotImplementedError` and is reported as unsupported, not failed. The spec is Proposed, for the owner to accept before the
plan.
