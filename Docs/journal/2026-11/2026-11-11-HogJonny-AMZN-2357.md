### The harness spec
**By:** @HogJonny-AMZN · **Agent:** Claude Code (claude-opus-5-5)

Written from the code, not the design's assumptions, and four things the design did not know came out of it: the suite's
pointwise limits for the originals are per feature (5e-5 to 1e-3, some with a correlation floor), not the comparison
table's classes; `simplex_billow` is compared twice, by point as classic Simplex and by shape as OpenSimplex2; 32
FastNoiseSIMD files are read by no test and become advisory cases rather than vanish; and `NoiseParams` has no
`to_dict`/`from_dict`, so the spec adds them. A partial port (the GPU rung's first 2D OpenSimplex2) raises
`NotImplementedError` and is reported as unsupported, not failed. The spec is Proposed, for the owner to accept before the
plan.
→ [the spec](../../superpowers/specs/2026-11-11-conformance-harness.md)

### Copilot on the spec
**By:** @HogJonny-AMZN · **Agent:** Claude Code (claude-opus-5-5)

All four findings on [PR #12](https://github.com/HogJonny-AMZN/HogNoise/pull/12) held. The coordinate files had no digest,
so an edited point file would have changed every case on it without an error; one `files` map now digests every `.f32`
file and `load` checks it. A zero bound had an undefined normalised difference (0/0); it is now 0 on a pass and infinity
on a fail. The spec said FastNoiseSIMD's originals cannot be regenerated, where ADR-007 records a source build working on
3.12 and 3.13; it now says they are costly to regenerate. And `portability.md` carries the run's date, so the byte-for-byte
check now drops that one line.
→ [the spec](../../superpowers/specs/2026-11-11-conformance-harness.md)

### Copilot's second pass on the spec
**By:** @HogJonny-AMZN · **Agent:** Claude Code (claude-opus-5-5)

FastNoiseLite `grid_3d` arrays are only drawn on the sheet, never compared, so the facts table now says so and their

`Docs/standards/workflow.md` requires, with module and kind from the manifest and none of the files in the lock.

### Copilot's late review on #13: fetch first
**By:** @HogJonny-AMZN · **Agent:** Claude Code (claude-opus-5-5)

Copilot's review of [PR #13](https://github.com/HogJonny-AMZN/HogNoise/pull/13)'s last commit landed two minutes after it
merged, with one valid finding: P-5's ancestry check runs against `origin/main`, which nothing updates without a fetch, so
straight after a merge it can call a merged commit missing. The ledger is append-only, so P-7 supersedes P-5's check:
`git fetch origin && git merge-base --is-ancestor <commit> origin/main`.
