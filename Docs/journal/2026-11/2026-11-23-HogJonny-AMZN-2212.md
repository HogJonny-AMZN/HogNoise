[The plan](../../superpowers/plans/2026-11-23-emitted-shaders-ci-proof.md) covers the spec's first pull request alone:

risk, with `xvfb-run` as the fallback.

own plan later, and each is now a row of its own:

- [the HLSL on WARP](../../plan/board/2026-11-23-the-emitted-hlsl-runs-on-warp.md), which the buffer-limit refusal waits on;

host built after wgpu passed against a mutant that never made its context current, because it ran wgpu before making
the context, the order that does not fail. Rewritten to the spec's order, it fails that mutant with `cannot create
program`, as the spec's probe did.

The engine trials wait on both, and the fresh-sample bounds wait on the first pull request's row. Each wait is now a
link the check reads.
