the context, the order that does not fail. Rewritten to the spec's order, it fails that mutant with `cannot create
program`, as the spec's probe did.

The engine trials wait on both, and the fresh-sample bounds wait on the first pull request's row. Each wait is now a
link the check reads.

### The CI proof's first pull request, built
**By:** @HogJonny-AMZN · **Agent:** Claude Code (claude-opus-5-5)

@HogJonny-AMZN accepted the plan ("I accept your recommendations"). The acceptance and the ledger's P-23 went in the
first commit of [PR #49](https://github.com/HogJonny-AMZN/HogNoise/pull/49), and the build followed the plan task by task.

- **The spec's first open risk is settled.** The hosted Ubuntu runner gives moderngl an EGL context on llvmpipe, OpenGL
  4.5, Mesa 26.0.8.
- **The two hosts run.** `noise.spv` runs through wgpu on WARP, llvmpipe and Metal, and the GLSL in moderngl on
  llvmpipe. Every hog case passed within `wgpu.json`, unmodified.
- **Metal is the exception to bit for bit.** `sample_points_3d` differs from the rung by up to 3.58e-7 there, within
  the tolerance. The test now holds the claim where it was measured, and is an expected failure elsewhere.
- **OpenGL joined the measured set** by its own XPASS: the `glsl` job's wgpu found llvmpipe through OpenGL.
- **Every instrument was mutated once and failed**, including the target check in CI itself.
- **Copilot's review found four real gaps.** The first: the `glsl` job required llvmpipe, but lavapipe, Mesa's Vulkan
  driver, has the same name, so "SPIR-V on OpenGL" was not pinned. It is now pinned and asserted (P-22 again). The
  others: the GL target was read before its context was current; the output was read without a buffer-update barrier;
  and the tables' missing and unreadable paths had no test. A fake context now records what the host calls, and each
  fix's mutant fails its test. The barrier cannot fail on llvmpipe or the 5090, which are coherent in practice. The
  test holds the order the OpenGL spec asks for.
