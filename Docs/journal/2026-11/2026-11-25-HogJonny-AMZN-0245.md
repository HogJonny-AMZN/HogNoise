### The DCC hosts
**By:** @HogJonny-AMZN · **Agent:** Claude Code (claude-opus-5-5)

HogHydra's session asked whether HogNoise would lock to the shared versions the owner's repositories now share
(LargeWorlds owns [the table](https://github.com/HogJonny-AMZN/LargeWorlds/blob/main/Docs/knowledge/shared-dependency-versions.md)).
The owner answered for HogNoise: it supports a range, and it must import in every supported DCC host on that host's own
Python and numpy. Their host list, and the versions read, are in [the DCC hosts](../../standards/compatibility-matrix-project.md):
Maya 2026, Houdini 21 and Unreal 5.8 at Python 3.11 with numpy 1.26.4, Blender 5.2 at 3.13 with numpy 2.3.4. HogHydra read
Maya, Blender and Marmoset inside each host through HogShade's BATS. This session read Houdini and Unreal from their install
files. Marmoset Toolbag 4 runs Python 3.9.4 with no numpy; the owner would move to Toolbag 5 before solving for it.

Two facts set what was built. The numpy floor was once raised to 2.x and that "wasn't the right direction"; the
[numpy 2 row](../../plan/board/2026-11-15-numpy-2-modernisation.md) already held the owner's 2026-11-15 answer, a 2.5+ path
beside the 1.26 one, never instead. And Dependabot rewrites declared requirements, not only the lock: it raised
`uv-build`'s floor twice ([PR #28](https://github.com/HogJonny-AMZN/HogNoise/pull/28),
[PR #47](https://github.com/HogJonny-AMZN/HogNoise/pull/47)). So Dependabot is held to the lock
(`versioning-strategy: lockfile-only`, which its schema accepts for uv), and `test_dcc_host_floors.py` refuses a raised
floor or a cap with the reason in its message: mutated to numpy 2.0, to a cap below 2.6 and to Python 3.12, it failed each
time, one test each. The floor leg is named for the three hosts it stands for, and Blender 5.2 has its own.

The fresh-sample bounds' plan merged ([PR #56](https://github.com/HogJonny-AMZN/HogNoise/pull/56)); the owner's "fix up and
then do both" set it Accepted here and the row In progress, and its build follows in its own pull request.
