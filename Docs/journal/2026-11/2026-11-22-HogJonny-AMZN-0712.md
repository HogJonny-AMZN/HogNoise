### The CI proof's spec: the shipped SPIR-V and GLSL run for the first time
**By:** @HogJonny-AMZN · **Agent:** Claude Code (claude-opus-5-5)

After [PR #42](https://github.com/HogJonny-AMZN/HogNoise/pull/42) merged, @HogJonny-AMZN said "your best
recommendations". Next in the account's order was gap 4, the CI proof. It brings new dependencies and a C++ harness,
so it starts as a spec with five decisions for the owner. Two facts were measured first, on the 5090. The shipped
`noise.spv`, read back through wgpu's SPIR-V front end and bound as the shaders README says, gave the WGSL rung's
numbers bit for bit on Vulkan and D3D12, for every entry point. The shipped GLSL ran in moderngl, bound by the
manifest's block names, within 1.73e-6 of the WGSL on Vulkan. Each probe had a seed-plus-one control that it failed.
One surprise: once wgpu had built its pipelines, moderngl could not create a program until its own GL context was
made current again.

The review of PR #42 found a CI leg that proved an adapter existed, not the back end it was named for. That is now
ledger P-22, and the spec applies it to each host harness.
